# word-dictionary
Simple vocabulary app for learning languages
To save and learn words in different languages

## Features
Add words with pronunciation and translation.
Choose language from a list (or type your own).
Save words in localStorage (so they don't disappear after reload).
Delete words with a confirmation dialog.

## Built with
- HTML5
- CSS3 (Grid)
- Vanilla JavaScript
- localStorage

## How to run
Clone the repo and open index.html

## What I learned
I learned how to use JSON.stringify for `localStorage` and how to find the correct index for deleting words.
